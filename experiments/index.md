# 著名实验

本分类详细记录验证量子力学原理的经典实验与思想实验。按实验性质分为**波粒二象性验证**、**量子化与原子结构**、**纠缠与非局域性**以及**思想实验**四大类。

## 波粒二象性验证

直接证实光与物质具有波粒二象性的关键实验。

| 文章 | 描述 |
|------|------|
| [双缝实验](double-slit-experiment) | 量子力学中最具标志性的实验。费曼曾评价其"包括了量子力学唯一的奥秘"。 |
| [光电效应实验](photoelectric-effect-exp) | 从 1887 年赫兹的偶然发现到 1916 年密立根的精确验证，逐步证实光的粒子性。 |
| [康普顿散射](compton-scattering) | 1923 年康普顿发现 X 射线被电子散射后波长变长，为光的粒子性提供了决定性实验证据。 |
| [戴维逊-盖末实验](davisson-germer) | 1927 年贝尔实验室完成的电子衍射实验，首次直接证实德布罗意物质波假说。 |

## 量子化与原子结构

证实原子能级量子化与空间量子化的里程碑实验。

| 文章 | 描述 |
|------|------|
| [弗兰克-赫兹实验](franck-hertz-experiment) | 1914 年弗兰克与赫兹通过电子-汞原子碰撞，首次从实验上直接证实原子能级的量子化。 |
| [斯特恩-盖拉赫实验](stern-gerlach-experiment) | 1922 年斯特恩与盖拉赫发现银原子束在非均匀磁场中分裂为两束，首次直接证实空间量子化与电子自旋。 |

## 纠缠与非局域性

检验量子纠缠与贝尔不等式的关键实验。

| 文章 | 描述 |
|------|------|
| [Aspect 实验](aspect-test) | 1981–1982 年阿兰·阿斯佩等人完成的贝尔不等式高精度检验，首次关闭局域性漏洞。 |
| [EPR 悖论](epr-paradox) | 1935 年爱因斯坦、波多尔斯基与罗森提出的思想实验，挑战量子力学的完备性。 |

## 思想实验

以理想化方式揭示量子力学深层矛盾与哲学含义的实验构想。

| 文章 | 描述 |
|------|------|
| [薛定谔的猫](schrodingers-cat) | 1935 年薛定谔提出的著名思想实验，揭示量子叠加在宏观尺度上的悖论性后果。 |
| [光子箱实验](photon-box) | 1930 年爱因斯坦在第六次索尔维会议上提出的思想实验，玻尔利用广义相对论完美反驳。 |
