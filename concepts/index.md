# 核心概念

本分类系统梳理量子力学的核心概念，按照 **"经典物理的黄昏 → 量子世界初探 → 数学框架 → 核心原理 → 动力学与近似 → 应用与前沿"** 的学习路径组织。前两阶段建立量子论诞生的物理动机，中间三阶段补齐严格量子力学所需的数学与动力学工具，最后连接现代应用。

> 📚 **Total articles:** 30

---

## 阶段一：经典物理的黄昏

> **目标**：引发好奇，展示经典物理的理论危机，为量子革命铺垫。

| 文章 | 核心要点 |
|------|----------|
| [黑体辐射](black-body-radiation) | 理想化物体的电磁辐射规律，经典理论无法完整解释 |
| [紫外灾难](ultraviolet-catastrophe) | 经典理论预言黑体在高频辐射能量无限大，与实验严重矛盾 |
| [光电效应](photoelectric-effect) | 光的波动理论无法解释电子逸出与光频率的依赖关系 |
| [能量量子化](energy-quantization) | 普朗克首次提出能量只能以离散单位发射或吸收 |
| [光量子](photon) | 爱因斯坦提出光由粒子（光子）组成，解释光电效应 |

**关键人物**：普朗克、爱因斯坦

## 阶段二：量子世界初探

> **目标**：建立量子化、波粒二象性、物质波与早期原子模型等核心概念。

| 文章 | 核心要点 |
|------|----------|
| [波粒二象性](wave-particle-duality) | 微观粒子在不同实验条件下既可表现为波，也可表现为粒子 |
| [量子化与能级](quantization-energy-levels) | 原子中电子只能存在于离散的能级上 |
| [氢原子](hydrogen-atom) | 最简单的原子系统，量子力学的理想试验场 |
| [矩阵力学](matrix-mechanics) | 海森堡、玻恩和约当于 1925 年创建的第一种完整量子力学形式 |
| [物质波](matter-wave) | 德布罗意提出所有物质都具有波动性 |
| [互补原理](complementarity-principle) | 玻尔提出波动性和粒子性是微观客体互补的两个方面 |

**关键人物**：玻尔、德布罗意、海森堡、玻恩、约当

## 阶段三：数学框架

> **目标**：补齐从直观量子现象进入严格理论所需的状态、概率、算符与测量语言。

| 文章 | 核心要点 |
|------|----------|
| [希尔伯特空间](hilbert-space) | 量子态构成的抽象向量空间，是现代量子力学的数学舞台 |
| [量子态](quantum-state) | 统一理解态矢量、波函数、纯态、混合态与密度算符 |
| [波函数](wave-function) | 量子态在位置表象下的概率幅表示 |
| [玻恩规则](born-rule) | 把概率幅与测量概率相联系的核心规则 |
| [密度矩阵](density-matrix) | 连接混合态、退相干、测量理论与量子信息的通用状态表示 |
| [算符理论](operator-theory) | 描述可观测量与系统状态关系的数学框架 |
| [可观测量](observables) | 自伴算符、本征值、本征态与测量公设的物理解释 |
| [对易关系](commutator) | 不确定性原理、矩阵力学和相容测量的代数基础 |

**关键人物**：狄拉克、冯·诺依曼、玻恩

## 阶段四：核心原理揭秘

> **目标**：深入不确定性、叠加、坍缩、纠缠、退相干等量子力学核心原理。

| 文章 | 核心要点 |
|------|----------|
| [海森堡不确定性原理](uncertainty-principle) | 无法同时精确测量粒子的位置和动量 |
| [量子叠加态](quantum-superposition) | 量子系统可同时处于多个状态的相干叠加 |
| [波函数坍缩](wave-function-collapse) | 测量导致量子系统从叠加态塌缩到确定结果的传统表述 |
| [量子纠缠](quantum-entanglement) | 多体量子态中不能分解为各部分独立状态的非经典关联 |
| [退相干](decoherence) | 环境相互作用导致相干项快速消失，解释经典世界的涌现 |
| [贝尔定理](bell-theorem) | 以不等式形式区分局域隐变量理论与量子力学预测 |
| [自旋](spin) | 粒子的内禀角动量，是 Stern-Gerlach 实验和量子比特的核心自由度 |

**关键人物**：海森堡、薛定谔、爱因斯坦、贝尔、祖雷克

## 阶段五：动力学与近似方法

> **目标**：理解量子系统如何随时间变化，以及真实系统如何通过近似方法求解。

| 文章 | 核心要点 |
|------|----------|
| [薛定谔方程](schrodinger-equation) | 非相对论量子态时间演化的基本方程 |
| [哈密顿量](hamiltonian) | 生成时间演化并通常代表系统总能量的算符 |
| [时间演化](time-evolution) | 封闭系统的幺正演化、能量表象与不同绘景 |
| [微扰理论](perturbation-theory) | 从可解模型出发处理小修正的核心近似方法 |

**关键人物**：薛定谔、狄拉克、朗道
