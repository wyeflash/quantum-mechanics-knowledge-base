# 历史事件

本分类按时间线记录量子力学发展历程中的重要里程碑，从 19 世纪末的经典物理危机，到 20 世纪 20—30 年代量子力学形式体系建立，再到 1960—1980 年代现代量子基础实验兴起。

## 经典物理危机（19 世纪末—20 世纪初）

经典物理学面临的理论困境与初步突破。

|------|------|
| [经典物理的危机](classical-physics-crisis) | 19 世纪末经典物理学面临的三大理论危机：黑体辐射、光电效应与原子稳定性问题。 |
| [原子稳定性问题](atomic-stability-problem) | 卢瑟福核式模型的经典电磁灾难与玻尔的初步解决。 |
| [1900：普朗克的量子假说](1900-planck-quantum-hypothesis) | 1900 年 12 月 14 日，普朗克提出能量量子化假说，被视为量子力学的诞生日。 |
| [1905：爱因斯坦的奇迹年](1905-einstein-miracle-year) | 爱因斯坦发表四篇创造性论文，光量子假说成为量子革命的重要里程碑。 |

## 旧量子论（1913—1924）

玻尔模型与早期量子化尝试。

| 文章 | 描述 |
|------|------|
| [1913：玻尔原子模型](1913-bohr-atomic-model) | 玻尔提出量子化原子模型，首次系统性将量子假说应用于原子结构，成功解释氢原子光谱。 |
| [1924：德布罗意物质波](1924-de-broglie-matter-wave) | 德布罗意提出所有物质粒子都具有波动性，将波粒二象性从光延伸至所有物质。 |

## 量子力学建立（1925—1927）

矩阵力学、波动力学、概率诠释与不确定性原理共同构成现代量子力学的核心基础。

| 文章 | 描述 |
|------|------|
| [1925：海森堡矩阵力学](1925-heisenberg-matrix-mechanics) | 海森堡发明矩阵力学，用代数方法彻底放弃经典轨道概念。 |
| [1926：薛定谔波动力学](1926-schrodinger-wave-mechanics) | 薛定谔建立波动力学和本征值问题形式，使量子理论获得微分方程表述。 |
| [1926：玻恩概率诠释](1926-born-probability-interpretation) | 玻恩提出波函数模平方给出概率分布，将波函数理解为概率幅。 |
| [1927：不确定性原理的提出](1927-uncertainty-principle) | 海森堡提出共轭量不能同时任意精确确定，奠定量子测量与互补性的基础。 |
| [1927：第五次索尔维会议](1927-fifth-solvay-conference) | 被誉为“现代物理学史上最重要的会议”，爱因斯坦与玻尔展开激烈论战，哥本哈根诠释由此确立。 |
| [1927：索尔维会议](1927-solvay-conference) | 第五次索尔维会议（量子力学会议）的综合概述。 |
| [索尔维会议](solvay-conference) | 由欧内斯特·索尔维资助的国际物理学会议系列，是 20 世纪物理学发展的重要舞台。 |

## 形式化与基础争论（1930—1935）

量子力学的统一表述、数学公理化与完备性争论。

| 文章 | 描述 |
|------|------|
| [1930：狄拉克《量子力学原理》](1930-dirac-principles-of-quantum-mechanics) | 狄拉克统一矩阵力学、波动力学和变换理论，推广 bra-ket 与抽象态矢量语言。 |
| [1932：冯·诺依曼《量子力学的数学基础》](1932-von-neumann-mathematical-foundations) | 冯·诺依曼以希尔伯特空间、算符和投影测量公理化量子力学。 |
| [爱因斯坦-玻尔论战](einstein-bohr-debate) | 20 世纪最著名的科学论战，持续近三十年，深刻影响了量子力学基础理论的发展方向。 |
| [1935：EPR 悖论](1935-epr-paradox-paper) | 爱因斯坦、波多尔斯基与罗森提出思想实验挑战量子力学完备性，引发长达数十年的学术论战。 |

贝尔定理和 Aspect 实验将 EPR 争论转化为可检验的现代量子基础研究。

| 文章 | 描述 |
|------|------|
| [1964：贝尔定理](1964-bell-theorem) | 贝尔证明定域隐变量理论必须满足可检验不等式，而量子纠缠可违反这些不等式。 |
