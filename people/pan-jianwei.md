# 潘建伟 (Pan Jianwei, 1970–)

## 概述

**潘建伟**是中国量子物理学家，全球量子通信领域最具影响力的研究者之一。他率领团队完成了多项全球首创性实验，包括“墨子号”量子科学实验卫星、千里级地面量子信道分发和十光子纠缠。他的工作为量子网络的实际应用奠定了关键基础。

::: info 可信度说明
- **可信度**: ★★★★★（基于 Pan 等人 1998–2012 原始论文、Nature/Science 发表论文及《自然》《科学》评论交叉验证）
- **验证状态**: 已验证
- **来源**: [1][2][3][4]
:::

## 生平

- **1970年**: 出生于浙江省东阳市
- **1992年**: 中国科学技术大学本科毕业
- **1999年**: 获得奥地利因斯布鲁克大学博士学位，导师为 Anton Zeilinger
- **2001年**: 回国工作，加入中国科学技术大学
- **2011年**: 当选中国科学院院士
- **2016年**: “墨子号”卫星成功发射，他担任总设计师
- **2017年**: 实现千里级地面量子密钥分发（“京沪干线”）
- **2020年**: 实现 500 公里级实时量子纠缠分发

## 主要学术贡献

### 1. 量子纠缠交换（Entanglement Swapping）（1998）

潘建伟在 Zeilinger 团队期间参与了全球首次**量子纠缠交换**实验 [1]：

> 两个从未相互作用的光子，可以通过一个中间纠缠对被"突然"纠缠在一起。

这一实验证明了**量子纠缠是可以被远程操纵的物理资源**，为后续的量子中继、量子网络和量子分布式计算奠定了基础。

### 2. 多光子纠缠

潘建伟团队在多光子纠缠领域创造了多项世界纪录：
- 2003年：八光子纠缠
- 2016年：十光子纠缠
- 2020年：十二光子纠缠

这些实验推动了**量子计算的光子实验平台**发展。

### 3. “墨子号”卫星

2016年8月16日，世界首颗量子科学实验卫星**“墨子号”成功发射**。潘建伟作为总设计师，设计了：
- 星地量子通信系统
- 星间量子通信验证

墨子号成功实现了：
- 星地之间的量子密钥分发
- 星间的 Bell 不等式检验
- 中继量子通信（地面站与卫星）

### 4. 千里级地面量子信道

2017年，潘建伟团队在**京沪干线**上实现了 1,200 公里的量子密钥分发 [3]，创下了地面量子信道距离的世界纪录。

## 学术地位与评价

潘建伟被认为是全球量子通信领域的领军人物之一。他的研究特点是：
- 将**基础研究**与**实际应用**紧密结合
- 利用光子**分布式量子处理**技术
- 在**星地量子通信**领域处于全球领先地位

## 流传误区

::: warning
- **误区一**: "墨子号实现了超光速通信。"
  - **澄清**: 量子纠缠**不能**用于超光速传递信息。墨子号实现的是**量子密钥分发**（QKD），这是一种安全的加密方式，而非超光速传信。
- **误区二**: "潘建伟是墨子号的唯一贡献者。"
  - **澄清**: 墨子号是中国科学院多个单位协作的大型科学工程项目，潘建伟作为总设计师负责整体架构，但数百名科学家和工程师参与了这一项目。
:::
