# 量子先驱

本分类记录量子力学发展历程中做出重大贡献的科学家与思想家，包括量子力学的奠基人、实验与统计先驱、数学形式化者以及当代中国量子科学家。

## 量子力学奠基人（国际）

20 世纪初开创量子力学的核心人物，建立了量子力学的理论框架与数学形式。

| 文章 | 描述 |
|------|------|
| [马克斯·普朗克](max-planck) | 德国理论物理学家，量子力学的创始人。1900 年提出能量量子化假说，1918 年获诺贝尔物理学奖。 |
| [阿尔伯特·爱因斯坦](albert-einstein) | 德裔理论物理学家，光量子假说的提出者，也是广义相对论与狭义相对论的创立者。1921 年获诺贝尔物理学奖。 |
| [尼尔斯·玻尔](niels-bohr) | 丹麦物理学家，玻尔原子模型与互补原理的提出者，哥本哈根学派领袖。1922 年获诺贝尔物理学奖。 |
| [路易·德布罗意](louis-de-broglie) | 法国物理学家，提出物质波假说，奠定波动力学基础。1929 年获诺贝尔物理学奖。 |
| [维尔纳·海森堡](werner-heisenberg) | 德国理论物理学家，矩阵力学与不确定性原理的创立者。1932 年获诺贝尔物理学奖。 |
| [埃尔温·薛定谔](erwin-schrodinger) | 奥地利理论物理学家，波动力学的创立者，提出薛定谔方程。1933 年获诺贝尔物理学奖。 |
| [马克斯·玻恩](max-born) | 德国理论物理学家，波函数概率诠释（Born 规则）的提出者。1954 年获诺贝尔物理学奖。 |
| [保罗·狄拉克](paul-dirac) | 英国理论物理学家，狄拉克方程、bra-ket 符号与反物质预言的提出者。1933 年获诺贝尔物理学奖。 |

## 实验与统计先驱

为量子力学奠定实验基础与统计力学基础的关键人物。

| 文章 | 描述 |
|------|------|
| [欧内斯特·卢瑟福](ernest-rutherford) | 新西兰裔英国物理学家，原子核物理之父，以 α 粒子散射实验发现原子核式结构闻名。1908 年获诺贝尔化学奖。 |
| [古斯塔夫·基尔霍夫](gustav-kirchhoff) | 德国物理学家，提出基尔霍夫热辐射定律，为黑体辐射研究奠定了理论基础。 |
| [路德维希·玻尔兹曼](ludwig-boltzmann) | 奥地利物理学家，统计力学奠基人之一，以玻尔兹曼熵公式闻名，为量子统计奠定了基础。 |

## 数学形式化与现代理论

将量子力学严格公理化或推动其现代基础检验的关键人物。

| 文章 | 描述 |
|------|------|
| [约翰·冯·诺依曼](john-von-neumann) | 匈牙利裔美国数学家，将量子力学严格公理化，建立希尔伯特空间形式体系，形式化了波函数坍缩假设。 |
| [约翰·贝尔](john-bell) | 北爱尔兰物理学家，以贝尔不等式闻名，为量子纠缠的非局域性提供了可实验检验的标准。 |

## 中国量子科学家

当代中国量子信息科学与技术领域的领军人物。

| 文章 | 描述 |
|------|------|
| [潘建伟](pan-jianwei) | 中国量子物理学家，"墨子号"量子科学实验卫星首席科学家，量子通信领域的领军人物。 |
| [郭光灿](guo-guangcan) | 中国量子信息学家，中国量子密码与量子通信研究的重要开拓者之一。 |
