# 实体

本分类记录量子力学领域的重要实体、机构与实验室。

## 研究机构与实验室

对量子力学发展产生深远影响的重要学术机构。

| 文章 | 描述 |
|------|------|
| [尼尔斯·玻尔研究所](niels-bohr-institute) | 1921 年由尼尔斯·玻尔在哥本哈根创立，量子力学的摇篮之一，培养了海森堡、玻恩、狄拉克等巨匠。 |
| [中国科学技术大学](university-of-science-and-technology-of-china) | 中国量子信息科学的核心阵地，墨子号、九章、祖冲之号等重大成果的诞生地。 |
| [卡文迪许实验室](cavendish-laboratory) | 1874 年创建于剑桥大学，电子、原子核、DNA 双螺旋的发现地，近代原子物理的发源地。 |
| [欧洲核子研究中心](cern) | 1954 年成立于瑞士日内瓦，世界最大粒子物理实验室，也是贝尔提出贝尔不等式的工作地。 |
| [马克斯·普朗克学会](max-planck-society) | 德国最大的基础科学研究组织，旗下拥有多个世界级量子光学与量子信息研究所。 |
| [慕尼黑大学与索末菲学派](ludwig-maximilian-university-munich) | 慕尼黑大学物理学系，索末菲培养了海森堡、泡利、贝特等一批量子力学奠基人，被称为"索末菲学派"。 |
| [苏黎世联邦理工学院](eth-zurich) | 瑞士顶尖理工大学，1920–40 年代是量子力学发展核心阵地，薛定谔、泡利、外尔等在此工作。 |
| [普林斯顿高等研究院](institute-for-advanced-study) | 1930 年成立于美国普林斯顿，爱因斯坦、冯·诺依曼等巨匠晚年工作地，量子力学数学基础与 EPR 悖论的诞生地。 |
