# QBism (Quantum Bayesianism)

## 概述

**QBism**（Quantum Bayesianism）是量子力学的一种信息论诠释，由 Christopher Fuchs、Rüdiger Schack、Carlton Caves 等人发展。它把量子态视为“行动者”（agent）对自身未来经验的个人概率判断，而不是外在系统的客观物理属性。

::: info 可信度说明
- **可信度**: ★★★★☆（基于 Caves–Fuchs–Schack 2002、Fuchs–Schack 2013 RMP 与 Fuchs–Mermin–Schack 2014 教学综述；哲学评价仍有争议）
- **验证状态**: 已验证；QBism 与标准量子力学经验预测一致。
- **来源**: [1][2][3][4]
:::

## 核心主张

### 1. 量子态是个人概率赋值

在 QBism 中，波函数 $|\psi\rangle$ 不是系统的客观状态，而是某个行动者根据其信息、经验和赌注一致性原则作出的概率赋值。这种概率是贝叶斯意义上的主观概率，不是频率主义意义上的客观倾向。

### 2. 玻恩规则是概率一致性约束

QBism 不把玻恩规则视为“自然界从波函数产生结果的机械规则”，而把它视为行动者不同实验赌注之间必须满足的一条规范性约束。它约束合理信念，而不是描述一个隐藏在背后的客观波函数机器。

### 3. 测量是行动者与世界的相互作用

测量不是被动读取预先存在的属性，而是行动者对世界采取行动并获得经验回应。结果对该行动者是真实的，但量子态更新类似贝叶斯条件化：它是信念更新，而非物理波函数在空间中坍缩。

## 对测量问题的回应

QBism 的策略是消解[[measurement-problem|测量问题]]中“波函数是否真实坍缩”的前提：如果波函数本来就是行动者的概率判断，坍缩就只是获得新经验后的信念更新。这与[[objective-collapse-theories|客观坍缩理论]]形成鲜明对比，后者把坍缩当成真实动力学过程。

## 与哥本哈根诠释的关系

QBism 常被看作哥本哈根传统的现代信息论后裔，但它比许多“教科书哥本哈根”更明确：

- 它明确采用个人主义贝叶斯概率；
- 它拒绝把“经典仪器”作为基本本体；
- 它强调行动者经验，但不等同于意识导致坍缩。

## 争议与批评

QBism 的主要争议在于科学实在论：如果量子态和概率都是个人判断，量子力学究竟告诉我们世界本身的什么结构？支持者回答说，玻恩规则本身揭示了世界对行动者经验的约束结构；批评者则认为这使量子力学过度接近工具主义。

## 当前学术共识程度

QBism 在量子信息与量子基础哲学中影响显著，但不是物理学主流工作语言。它提供了测量问题的强力概念重构，却通常不产生与标准量子力学不同的实验预测。

## 流传误区

::: warning
- **误区一**: “QBism 说世界不存在。”
  - **澄清**: QBism 并不否认外部世界；它否认量子态是外部世界的直接画像。
- **误区二**: “QBism 就是意识导致坍缩。”
  - **澄清**: QBism 的坍缩是概率信念更新，不是意识施加物理作用。
- **误区三**: “主观概率意味着任意胡猜。”
  - **澄清**: 贝叶斯概率受一致性规则和玻恩规则强约束；不同行动者可通过交流经验逐步校准判断。
:::
