# 量子力学诠释

本分类探讨量子力学的不同诠释框架、测量问题与哲学含义。阅读时应区分两类问题：

1. **经验预测**：多数诠释在标准量子力学范围内给出相同实验结果。
2. **本体论与解释**：它们对波函数、坍缩、概率、观察者与实在的理解不同。

::: info 资料来源原则
诠释类页面优先采用原始论文、*Reviews of Modern Physics* 综述、Stanford Encyclopedia of Philosophy、Cambridge/Oxford/Princeton 等学术出版社专著。对无实验证据区分的哲学主张，页面会标注“当前共识程度”而非当作已定论事实。
:::
