# 对比分析

本分类提供量子力学概念、理论、诠释与技术路线的对比分析。它的核心目的不是制造“二选一”的简单判断，而是帮助读者看清：哪些差异属于数学形式，哪些属于物理诠释，哪些属于实验事实，哪些属于工程应用边界。

::: tip 阅读建议
如果你想避免常见误解，优先阅读 **退相干与坍缩**、**经典概率与量子概率**、**量子纠缠与经典相关** 三篇。它们分别对应测量问题、概率诠释和非局域性的高频误区。
:::
